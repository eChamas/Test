Classes de Endereçamento IPv4

Na arquitetura TCP/IP v4, os endereços são divididos em 5 classes principais. Para identificar a classe de um IP, basta analisar a faixa numérica do 1º Octeto (primeiro byte).

Classe A 0 - 127
N.H.H.H

1 Byte para Rede (Net-ID) e 3 Bytes para Hosts. Utilizada para redes de altíssimo porte com até 16,7 milhões de máquinas.

Bit Inicial: 0...
Classe B 128 - 191
N.N.H.H

2 Bytes para Rede e 2 Bytes para Hosts. Projetada para corporações e universidades de médio a grande porte (até 65 mil hosts).

Bits Iniciais: 10...
Classe C 192 - 223
N.N.N.H

3 Bytes para Rede e 1 Byte para Host. Ideal para redes locais (LANs) pequenas ou residenciais (até 254 hosts por rede).

Bits Iniciais: 110...
Classe D: Multicast 224 - 239

Não dividida em Net-ID/Host-ID. Utilizada para transmissões de Multicast (envio de pacotes para múltiplos receptores simultaneamente, ex: streaming/roteamento).

Classe E: Reservados 240 - 255

Não utilizada em hosts comuns. Faixa reservada pela IANA para uso experimental, pesquisas científicas e desenvolvimentos futuros do protocolo.

Endereços Especiais e Reservados na Prática

0.X.X.X
Rede Corrente

Nenhum IP configurado em host pode começar com 0. Indica "esta rede" ou host não configurado.

127.X.X.X
Diagnóstico / Loopback

Utilizado para testes internos da própria placa de rede (ex: 127.0.0.1 localhost).

255.255.255.255

Broadcast Geral

Servindo como endereço de broadcast limitado para envio a todos os computadores da rede local.
